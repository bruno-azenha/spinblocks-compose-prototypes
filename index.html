Spinblocks — Compose prototypes

Three ways to feel block-size-first, then fill with atomic moves. Speed is implied by the move you pick — no dial.

Proto A

Block palette fill

Pick an 8 / 16 / 24 / 32 block, then tap atoms from a bottom palette to append. Remaining counts gate what fits; exact fill locks the block.

Proto B

Count grid paint

Same block sizes, but the counts are a paint grid. Select a move as brush, tap a start cell — tiles snap to baseMin multiples and never overlap.

Proto C

Stack fill

Block size is stack capacity. Push moves on, step lengths in baseMin increments, reorder with ↑↓ — satisfying meter when capacity is reached.
